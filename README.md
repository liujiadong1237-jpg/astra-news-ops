# Astra 资讯运营 Bot｜部署与接入说明

独立 Bot，不接入人生导师 / 도윤 协调体系。  
Bot 名称：**Astra资讯**  
在 Grok Bot 侧栏打开：[Astra资讯](grokbot://app/v1/agent?id=4c3bf188-e4b2-4eae-a42b-b236fb5931ac)

## 1. 部署方式（国内可用）

本 Bot **不是**单独服务器进程，而是跑在 Cursor / Grok Bot 云端的独立助手：

| 项目 | 说明 |
|---|---|
| 运行位置 | Grok Bot 云端 Agent（侧栏「Astra资讯」） |
| 调度 | Agent 内 **Routine（定时任务）**，建议每天白天固定一轮 |
| 本机要求 | 手机或电脑能打开 Grok Bot 即可；无需自建 VPS |
| 国内访问 | 对话与定时任务走 Cursor 服务；采集时优先可用源，被墙源改用可访问替代并标注 |

你不需要 `docker` / `pm2`。停用：在侧栏暂停该 Bot 的日程，或不用它即可。

## 2. 运行地址 / 进程说明

- **对话入口**：侧栏 → Astra资讯  
- **日程**：该 Bot 自己的 Routines（由 Bot 创建「每日资讯采集」）  
- **产出**：每日一轮摘要 + 可发布素材包出现在 **Astra资讯** 聊天里  
- **无公网 URL**：这是对话型 Bot，不是网站；看板类可视化见另仓库 `project-progress-board`

## 3. 四个源的接入配置

### X（Twitter）
- Grok Bot 已带 **公开 X 读取**（发帖/搜索），一般无需再登录。
- 配置：在日程提示里写清关键词（如 `shoe repair` `奢侈品修复` `寄修` `sneakers restoration`）。
- 限制：有每分钟/每日读取配额；只读不发帖（发帖另走用户确认）。

### Reddit
- 优先：公开 JSON / 旧版页面（若当前网络可访问）。
- 国内常被墙时的替代：用可访问的网页摘要、或用户粘贴帖子链接让 Bot 整理。
- 可选：用户提供 Reddit 只读脚本/第三方镜像地址（写入本目录 `config.sources.json`）。

### Discord
- Bot **不能**擅自进私人服。需要你：
  1. 指定公开邀请或你有权访问的频道；
  2. 或定期把频道精华导出/转发到 Astra资讯聊天。
- 没有官方 Discord 连接器时：用浏览器登录你的账号（仅在你授权的会话里），只读公开频道摘要。

### Perplexity
- 用网页问答做「今日主题检索」（浏览器）；或你把 Perplexity 分享链接贴进聊天。
- 国内若打不开：改用国内可访问的搜索/资讯站做同等主题检索，并在结果里标明来源替换。

示例配置文件见 `config.sources.example.json`。复制为 `config.sources.json` 后改关键词即可（给 Bot 看或交给会跑脚本的人）。

## 4. 闲鱼 / 小红书发布流程

**默认：只起草，不自动上架。**

1. 每日采集后，Bot 在聊天里给出：
   - 小红书：标题、正文、话题标签、配图建议、合规注意
   - 闲鱼：标题、描述、类目建议、价格区间建议（需你确认）
2. 你回复「改一下…」则改稿；回复「直接发小红书」或「直接发闲鱼」才进入发布。
3. 发布时 Bot 用自带浏览器打开对应站点；登录、验证码、支付由你确认。
4. 发布成功后回报链接；失败则保留草稿文案。

合规：不搬运未授权全文；海外来源做「信息来源 + 自己的改写」；不承诺虚假功效；闲鱼虚拟商品遵守平台规则。
